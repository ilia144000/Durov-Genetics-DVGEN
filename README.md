# Durov Genetics (DGEN)

**Durov Genetics (DGEN)** is an independent, community-oriented token concept on the TON blockchain, inspired by the widely reported story of Pavel Durov's 100+ biological children.

**100 heirs. One legendary DNA. Infinite possibilities.**

DGEN explores the intersection of digital culture, genetics, legacy, and decentralized communities.
