# TON Jetton Metadata

Jetton metadata can be published as an off-chain JSON document referenced by the jetton master contract, or on-chain depending on deployment. The publicly accessible metadata JSON must include the correct token name, symbol, decimals, and image URL.

Use `jetton.example.json` as a template only. Do not announce a contract address until verified on-chain. Note: editing GitHub files does not automatically update a deployed jetton's metadata URI.
