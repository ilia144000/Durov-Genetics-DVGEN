# Tonkeeper Integration Notes

1. Verify the actual DGEN jetton master contract address on TON mainnet.
2. Host a publicly accessible token icon (`../../assets/logo.png`) and metadata JSON matching the deployed jetton metadata.
3. Confirm the token displays correctly by adding or opening the verified jetton in a compatible TON wallet.
4. For discovery/listing or token recognition, follow the **current official Tonkeeper / TON asset submission requirements**; this repository alone does not guarantee a listing.
5. If building a dApp, use TON Connect and request permissions through the wallet rather than storing wallet secrets.

No wallet integration or listing has been activated by these documentation files.
